# C2-window-a1 — Window length L sweep at the default bandwidth (secondary to the probe)

*parent* `R0` · *contribution* C2 · *status* done · jobs 18/18

**Question.** With a raw input window of L samples instead of the full-history SFM context, how long must the window be?

**Hypothesis.** A window >= L* = ln(1/eta)/alpha (eta = 0.05) is within 5% of the longest window (sufficient direction of Corollary 1); shorter windows lose accuracy.

**Decision rule.** Supported if e(L >= L*) is within 5% of e(512) on >= 5/6 dev systems, on id and sequence_ood.
