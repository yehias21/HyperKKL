# C2-trunc-test — Truncated-history SFM context on the six HELD-OUT test systems (window rule, pre-registered)

*parent* `TEST-C1` · *contribution* C2 · *status* done · jobs 18/18

**Question.** How much input history does the decoder need? Corollary m2-rule: a window of L* = (ln(1/eta) + ln l)/alpha seconds suffices (eta = 0.05, l = Lipschitz constant of the inverse windowed map, proxy l_dec_q95). Tested with the SFM context whose filter state uses only the last H input samples (inputs older than H -> 0), in training and deployment alike, so every arm has the same trainable parameters (no capacity confound).

**Hypothesis.** (S) for every arm H with L*_i <= H <= 0.5 N_i the error is within +5% of the untruncated context (lora and hyper, id and sequence_ood); (T) at the largest arm H <= L*_i/4 the error is significantly worse. L*_i per system is fixed in experiments/memory/PREREG.md from the existing phase-1 l_dec_q95.

**Decision rule.** Supported if (S) holds on >= 4/6 systems AND (T) holds on >= 4/6 systems (analysis.evidence.analyse_trunc; paired relative change vs the same method's inf arm, Student-t over 3 seeds; (S) point estimate <= +5% on every informative arm, TOST at 5% reported; (T) 95% CI lower bound > 0). (S) alone on >= 4/6: 'sufficient bound supported, tightness not'. Systems with no arm in [L*_i, 0.5 N_i] are not testable for (S).

# Metric `nrmse`

Definitions in hyperkkl/metrics.py. Mean over training seeds with a Student-t 95% CI over seeds (single-seed nodes: episode bootstrap, which ignores training variability); lower is better. Paired cells: mean per-seed relative change vs the reference, negative = better, bold = CI excludes 0. µs/step: CPU, batch 1.
