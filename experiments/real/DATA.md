# Data provenance: Panasonic 18650PF Li-ion battery data

- **Dataset**: Panasonic 18650PF Li-ion Battery Data, Phillip Kollmeyer (tests performed at the University of Wisconsin-Madison).
- **Repository**: Mendeley Data, version 1, published 2018-06-21. **DOI**: [10.17632/wykht8y7tg.1](https://doi.org/10.17632/wykht8y7tg.1). Landing page: https://data.mendeley.com/datasets/wykht8y7tg/1
- **Licence**: CC BY 4.0 (http://creativecommons.org/licenses/by/4.0). Attribution: P. Kollmeyer, Panasonic 18650PF Li-ion Battery Data, Mendeley Data, v1, 2018, doi:10.17632/wykht8y7tg.1. The data are used unmodified; derived quantities (1 s resampling, SOC reference, filtered voltage channel) are computed by `hyperkkl/realdata.py`.
- **Cell / rig** (dataset readme): new 2.9 Ah Panasonic NCR18650PF cell, 8 cu.ft. thermal chamber, Digatron 25 A / 18 V channel; drive cycles logged at 0.1 s; charged at 1 C to 4.2 V (50 mA cut-off) before every test; drive cycles end at 2.5 V (25 degC) or at 80 % DOD (0 degC; no regen below 10 degC).
- **Metadata API used**: https://data.mendeley.com/public-api/datasets/wykht8y7tg (file list with per-file SHA-256); downloaded 2026-10-25 with curl (follows a redirect to the repository's S3 bucket).
- **Handling**: every file is in its own dataset directory `experiments/real/raw/panasonic18650pf/` (untrusted). Nothing from it is executed (the dataset's `Plot_results.m` was only read as text). Files are parsed with `scipy.io.loadmat` (MAT v5) by our own code, run as `.venv/bin/python -I` from outside the data directory.
- **Selection**: only what the experiment needs: the readme, 25 degC drive cycles (10 files), 25 degC C/20 OCV test and 1 C discharges, 25 degC HPPC (downloaded, unused), 0 degC drive cycles (10 files). Total ~52 MB of the 198 MB dataset.
