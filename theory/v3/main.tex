\paragraph{Reading guide.} \vthree{G1}{rewritten for the final method} The theory is about the observer as finally
defined: a fixed linear contracting latent filter, a strided window of $K=20$ past latents ($z$-window), a spectral
fading-memory (SFM) input context, and a low-rank hypernetwork decoder trained on mixed histories with the C5
regulariser (Definition~\ref{def:m1-default}). There is no input-dependent latent gain $B(c)$ and no latent injection in
the default. The benchmark covers autonomous and input-driven state estimation; the autonomous case is
Proposition~\ref{prop:m1-autonomous}.

Every statement carries a status tag: [proven] under the stated assumptions, [proven, linear plants], [conjecture], or
[empirical]; each is followed by an intuition, a proof, what it predicts and which experiment tests it (or that none
does). Proofs are written for the stated assumptions only; no claim is stronger than its proof. Statements that are new
or changed in v3 are marked \vthree{ID}{note}. Statements for the main text:
\begin{enumerate}[leftmargin=*,itemsep=1pt]
\item Lemma~\ref{lem:li-window} (\emph{main theoretical contribution}): an information limit for every observer with a
finite memory, a necessary condition. Its computed numbers at a window $W$ use the climatology as a Gaussian stand-in
for the prior at the window start, so they are an approximation (Remark~\ref{rem:li-prior}); window starvation is not
proven. The effective window of the default is at least $6/\alpha$ (Remark~\ref{rem:li-fading}), and every example uses
that corrected window.
\item Lemma~\ref{lem:m2-fir} and Theorem~\ref{thm:m2-window}: the $z$-window makes the latent an exact finite-memory map,
so the truncation tail and the initial transient cancel, and the $K=1$ lower bound does not carry over.
\item Proposition~\ref{prop:m1-where} (where the input enters) and Proposition~\ref{prop:m3-mismatch} (when a learned
observer beats a filter: model incompleteness).
\item Proposition~\ref{prop:m1-autonomous}: with no input the observer is a fixed filter plus a \emph{stationary} decoder
of the $z$-window, so the autonomous KKL guarantees apply in the form stated there.
\end{enumerate}
The Lyapunov dependence of the learned observer's error is an empirical observation (Remark~\ref{rem:li-scope}).
Proposition~\ref{prop:m3-iss} is a decomposition with measured constants, not a certificate. All numerical constants
quoted are produced by \texttt{theory/checks/*.py}; the v3 checks are in \texttt{theory/checks/v3\_checks.py}.
